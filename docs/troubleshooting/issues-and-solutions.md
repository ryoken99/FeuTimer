# Issues Encountered & Solutions

| # | Issue | Root Cause | Solution |
|---|---|---|---|
| 1 | Split APK resources (`en`, `es`, `pt`, `xhdpi`) not in base `br.com.isul.jiujitsutimertv.edambjj.apk`, and `apktool` CLI absent on host | Google Play App Bundle split delivery + binary `resources.arsc` / AXML format | Built direct binary `RES_TABLE_TYPE` (`resources.arsc`) and `RES_XML_TYPE` (AXML) decoders in Node.js to extract `R.array.presets`, all localized string tables, and all 7 XML layouts with 100% fidelity. |
| 2 | Purpose of 4000ms post-sound delay in `TimerFragment.playSound` unclear from Java code alone | `startTimer()` blinked for 4s before calling `play()` | Decoded `beep_pega.mp3`, `beep_fim.mp3`, `beep_respira.mp3`, and `wood_clap.mp3` via `afconvert` + 50ms RMS/zero-crossing DSP analysis, discovering `beep_pega.mp3` is a `3-2-1-HORN` sequence (`950Hz` pips at `0s, 1s, 2s` + `990Hz` horn at `3s`). Recreated as explicit `LEAD_IN` phase + `WavSynthesizer`. |
| 3 | Original `TimerFragment.nextRound()` bug when custom `restSeconds == 0` | Original code unconditionally toggled `isInterval = true` with `0ms` duration | Fixed in `TimerEngine.tickWork()` (covered by `TimerEngineTest`): when `restSeconds == 0`, transitions directly to the next round's `LEAD_IN` without a phantom rest tick. |
| 4 | Android Lint `NewApi` error on `ConcurrentHashMap.newKeySet()` | `ConcurrentHashMap.newKeySet()` requires API 24 while `minSdk` is 23 | Replaced with `Collections.newSetFromMap(ConcurrentHashMap<Int, Boolean>())` (API 1+); verified `lintDebug` passes with `No issues found`. |
| 5 | Missing local Android SDK & Gradle CLI on fresh workspace | Only Temurin JDK 21 was pre-installed under `~/.local/share/rea` | Installed official Android `commandlinetools`, `platforms;android-35`, `build-tools;35.0.0`, and Gradle `8.11.1` wrapper so unit tests, lint, and signed APK builds run locally offline. |
| 6 | Ambiguous preset card columns (`10 rep. \| 2 min. \| 3 min.`) carried over from `JJTimer-Edam` | Original `component_round_text_fixed.xml` only rendered units (`rep.`, `min.`, `min.`) without naming Fight vs Rest | Added explicit color-coded role labels (`RONDAS` · `LUTA` · `DESCANSO` / `ROUNDS` · `FIGHT` · `REST`) on every preset card in both `RoundsScreen.kt` (Android TV APK) and `web/` (macOS browser preview). |
| 7 | Non-Leanback Android TV Boxes & multi-remote edge cases (`INSTALL_FAILED_MISSING_FEATURE`, nested `.focusable().clickable()` double focus node, Touch-Mode Air-Mouse dongles) | Many academy HDMI boxes run standard AOSP Android OS without `android.software.leanback`, and Compose's `.clickable()` wraps an internal `FocusableInNonTouchMode` node | Set `android.software.leanback` to `android:required="false"` (while keeping both `LEANBACK_LAUNCHER` and `LAUNCHER` intents), refactored `TvFocusableSurface` to a single `focusable` node + `detectTapGestures` + `SurfaceKeyPressTracker`, and added `RemoteKeyClassifier` covering IR/BT TV remotes, HDMI-CEC (`ENTER`/`ESCAPE`), USB Air-Mouse dongles (`NUMPAD_ENTER`/`SPACE` + pointer clicks), media keys (`PLAY`/`PAUSE`/`PLAY_PAUSE`/`STOP`), and gamepads (`BUTTON_A`/`BUTTON_B`). |
